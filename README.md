# Tarea de Países en Java

Proyecto realizado para aplicar conceptos de Programación Orientada a Objetos.

## Tema
Países

## Lenguaje utilizado
Java

## Descripción
El programa utiliza una clase llamada Pais para representar diferentes países mediante atributos y acciones.

Se crearon 10 objetos correspondientes a diferentes países y posteriormente se almacenaron para mostrar sus datos en forma de tabla en la consola.

## Atributos
- Nombre
- Capital
- Continente
- Población
- Idioma
- Moneda
- Superficie

## Países utilizados
1. México
2. Canadá
3. Brasil
4. España
5. Francia
6. Alemania
7. Japón
8. China
9. Australia
10. Argentina

## Archivos principales

### Pais.java
Contiene los atributos, constructor y métodos de cada país.

### TablaPaises.java
Recibe los objetos y permite imprimirlos en forma de tabla.

### Main.java
Crea los 10 objetos y ejecuta el programa.
